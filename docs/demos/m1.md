# Milestone 1 demo — the viewer (in progress)

What exists so far: a tiled, continuously scrolling viewer, plus everything for finding your way
around a document in English and Arabic:

- a side panel with thumbnails, the outline and search;
- text selection that copies Arabic in reading order;
- recent files, session restore and the remembered position in each file;
- reading themes, a command palette and password-protected files.

Not yet: printing, multiple windows, the frame-rate measurement, and reading a document's own
right-to-left page order.

Setup once: `scripts/dev-setup.sh`, `(cd apps/desktop && pnpm install)`, `node fixtures/generate.mjs`.
On this Mac, first: `export PATH=/opt/homebrew/opt/rustup/bin:$PATH`.

```bash
cd apps/desktop && SAFHA_OPEN="$PWD/../../fixtures/out/chrome/contract-two-column.pdf" pnpm tauri dev
```

## 1. Reading (2 minutes)

1. The contract opens fitted to the width. Scroll and zoom with pinch or `⌘`+scroll; the zoom is
   anchored at the pointer. `⌘O` → `fixtures/out/derived/bilingual-1000-pages.pdf` opens at once;
   drag the scrollbar to the end. Pages show a preview at once, then sharpen.
2. Status bar: switch the page layout to **Two pages** or **Book**, and the page order to
   **Right to left** (Arabic books). The order is independent of the UI language.
3. Status bar, the last menu: **Pages: sepia** and **Pages: night** tint the pages and thumbnails,
   not the window.

## 2. Finding your way (3 minutes)

1. `F4` (or the panel button at the start of the status bar) opens the side panel with
   **thumbnails**. The current page is marked and follows scrolling; click one to jump.
   Arrow keys move between thumbnails.
2. The second panel button shows the **outline**. Choose an entry to go to its page.
3. `⌘O` → `fixtures/out/derived/page-labels.pdf`. The page field reads `i`, then `1`, `2`; type
   `2` and press Enter to go to the page *labelled* 2 (the third page).
4. `⌘F` opens **search**. Type `الايجار` without the hamza: it finds `الإيجار`. Turn on whole
   words, case, regular expressions, or `ة≈ه` with the toggles. Each hit is marked on its page;
   `⌘G` / `⇧⌘G` (or Enter / Shift+Enter in the field) step through hits, and the list follows.
   Typing `٢٠٢٦` finds `2026` (digit styles are equal).

## 3. Selecting and copying Arabic (2 minutes)

1. Drag across an Arabic line in the contract. The highlight follows the pointer. A **Copy**
   button floats above the selection; `⌘C` works too.
2. Paste into a text editor: the Arabic is in reading order, numbers and English names intact,
   not reversed.
3. Double-click a word to select it, triple-click to select its line, Shift-click to extend.
   `⌘A` selects the page's text; `Esc` clears.
4. In a mixed line ("اشتريت 3 أجهزة iPhone 15 Pro…" in `chrome/mixed-inline.pdf`), drag across
   just the English run: exactly those glyphs are selected and copied.

## 4. Remembering (1 minute)

1. Scroll the 1,000-page file to page 500 and quit. Launch again (`pnpm tauri dev` without
   `SAFHA_OPEN`): both tabs come back, and the big file reopens at page 500, same zoom.
2. Close every tab: the start screen lists **recent files**, with ones that were moved or deleted
   marked. The `×` forgets one; **Clear recent files** forgets all.
3. Language, theme, page colours, the open panel, and search options persist too.

## 5. Protected files and the palette (1 minute)

1. `⌘O` → `fixtures/out/derived/encrypted.pdf`: an inline prompt asks for the password. A wrong
   one says so and lets you try again; `safha-test` opens it. The password is not kept.
2. `⌘K` opens the **command palette**. Type `night`, or `ليلي` — every command matches by its
   English or Arabic name, whatever the UI language — and press Enter.
3. Switch the UI to Arabic (the language button): the side panel moves to the right with the tool
   rail, search results read in their own direction, and the outline indents from the right.

## 6. Smoothness (2 minutes, screen unlocked)

```bash
cargo build -p safha-desktop --features devtools && scripts/scroll-benchmark.sh /tmp/scroll debug
```

The app opens the 1,000-page file and drives itself:

- 40 random jumps;
- scrolling at 4,000 and 12,000 px/s, and a fling;
- pinching in to 7× and out to 0.35×.

The table shows dropped frames and blank time per phase, and memory. In the release build
(ADR 0011):

- scrolling drops no frames and no page stays blank longer than 12 ms;
- the extreme pinch-out drops a few frames, which is still an open item.

## Checks behind this demo

- `cargo test --workspace` (core: text, search, rotation, index cache, store; shell: password,
  reopening, remembered position) and `cd apps/desktop && pnpm test` (selection model, search
  commands, shortcuts, palette matching, password prompt).
- `scripts/selftest.sh <pdf> <out> en|ar light|dark` then
  `node scripts/check-selftest.mjs <out> ltr|rtl`. In the real app this runs select-all on
  page 1 and compares the copy with the page's text, searches a word from it and checks the
  hits are marked, and waits for a thumbnail.
