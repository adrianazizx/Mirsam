# Milestone 0 demo — foundations

What exists after M0: a Tauri window with the full app layout in English and Arabic, PDFium bound
in the Rust core and rendering a page to a canvas, a generated test corpus, an OCR evaluation
scorer with a first baseline, and two spikes with measurements. No viewer features yet — no
scrolling through a document, no selection, no search. Those are Milestone 1.

Setup once: `scripts/dev-setup.sh`, `(cd apps/desktop && pnpm install)`, `node fixtures/generate.mjs`.
On this Mac, first: `export PATH=/opt/homebrew/opt/rustup/bin:$PATH`.

## 1. The app (2 minutes)

```bash
cd apps/desktop && MIRSAM_OPEN="$PWD/../../fixtures/out/chrome/mixed-inline.pdf" pnpm tauri dev
```

1. The window opens with the fixture already showing: Arabic lines with English names, numbers,
   and Arabic-Indic digits, rendered by PDFium and fitted to the window width.
2. Resize the window: the page re-fits (the old bitmap stretches for an instant, then sharpens).
3. Status bar: zoom in/out (`⌘+` / `⌘−`), fit width (`⌘2`), actual size (`⌘1`).
4. Click the language button (top bar). The whole layout mirrors: tool rail moves to the right,
   inspector to the left, the tab hugs the right edge, chevrons flip. **The page does not
   mirror** — document direction is independent of UI direction.
5. Click the theme button: dark theme. The page stays white paper.
6. `⌘⇧D` opens the design gallery: every token and base component, in the current language and
   theme. `⌘⇧D` again to close. (It was `⌘⇧G` in M0; that is now "previous search result".)
7. `⌘O` → pick `fixtures/out/derived/bilingual-1000-pages.pdf`. It opens instantly; `PgDn` /
   `PgUp` move through pages. Pick `fixtures/out/derived/encrypted.pdf`: a plain-language inline
   message (no modal) says protected files are not supported yet.

## 2. The same thing, verified without a human

```bash
cargo build -p mirsam-desktop --features devtools
scripts/selftest.sh fixtures/out/coretext/contract-two-column.pdf /tmp/mirsam-selftest ar dark
node scripts/check-selftest.mjs /tmp/mirsam-selftest rtl
open /tmp/mirsam-selftest/canvas.png     # the pixels the webview's canvas actually holds
```

## 3. The corpus and the Arabic extraction baseline

```bash
cargo run -p mirsam-core --example fixture_report
```

Shows, per fixture, how many expected logical-order blocks PDFium's raw text already contains:
all of the English ones, none of the pure-Arabic ones (46 of 118 overall). This is the problem
Milestone 1's reading-order work has to solve, as a number.

## 4. OCR evaluation

```bash
node ocr-eval/generate.mjs
swift ocr-eval/engines/apple-vision.swift ocr-eval/out/manifest.json ocr-eval/out/hyp/apple-vision
cargo run -p mirsam-ocr-eval -- --manifest ocr-eval/out/manifest.json \
  --hyp ocr-eval/out/hyp/apple-vision --engine apple-vision --targets ocr-eval/targets.json
```

macOS's built-in OCR passes the clean-Arabic gate and fails the mixed-text and numbers gates —
the scorer separates recognition errors from reading-order errors, which is where it fails.
